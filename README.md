# App Legendas — atualizações

Instaladores do App Legendas (extensão para o Adobe Premiere Pro). O painel instalado lê
`latest.json` para avisar quando há uma versão nova.

Para instalar manualmente, baixe o `.exe` da [última versão](../../releases/latest), feche o
Premiere, execute o instalador e abra **Janela > Extensões > App Legendas**.

Este repositório só guarda os instaladores; o código-fonte é privado.
